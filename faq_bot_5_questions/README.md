# FAQ-бот на 5 вопросов

Небольшой терминальный FAQ-бот для репетиции HackAlem AI.

## Что делает бот

Бот отвечает на 5 заранее известных тем:

1. время репетиции;
2. участие командой;
3. трек;
4. сдача решения;
5. призы.

Поиск ответа выполняется по ключевым словам и простым тематическим алиасам.  
RAG, внешние API и LLM не используются.

Если вопрос не похож ни на одну из 5 тем, бот отвечает:

```text
не знаю
```

## Структура

```text
faq_bot_5_questions/
├── main.py
├── faq.txt
└── README.md
```

## Требования

- Python 3.10+;
- сторонние библиотеки не нужны.

## Запуск

### Windows

```bash
python main.py
```

Если команда `python` не работает:

```bash
py main.py
```

### Linux / macOS

```bash
python3 main.py
```

## Пример работы

```text
FAQ-бот HackAlem AI — репетиция

Вы: Когда будет репетиция?
Бот: Репетиция пройдет перед основным хакатоном. Точное время смотрите в сообщении организаторов или в расписании мероприятия.

Вы: Можно проходить командой?
Бот: Да. Репетицию можно проходить в составе своей команды. Используйте тот же командный формат, который планируете на основном хакатоне.

Вы: Есть призы?
Бот: Нет. Репетиция нужна для тренировки перед HackAlem AI, призов за нее нет.

Вы: Какая сегодня погода?
Бот: не знаю
```

## Как изменить ответы

Откройте `faq.txt`. Формат каждой записи:

```text
Q: вопрос
A: ответ
```

Между записями оставляйте пустую строку. В файле должно быть ровно 5 пар вопрос–ответ.

## Что получилось

Получился легкий терминальный FAQ-бот без RAG. Он загружает 5 пар из `faq.txt`, нормализует пользовательский вопрос, сравнивает его с известными вопросами по ключевым словам и печатает наиболее подходящий ответ. Если совпадение недостаточное, выводится `не знаю`.
